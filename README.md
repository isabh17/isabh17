relacionales.

Estudié Ingeniería en Ciencias y Sistemas en la Universidad de San Carlos.

## Cosas que he hecho

**[Bases de datos en Oracle](https://github.com/isabh17/bases-de-datos-oracle)**
Dos sistemas llevados desde el modelo conceptual hasta la implementación. El
primero es un comercio con su API en Flask; el segundo, un sistema bancario
donde la lógica de las transacciones vive en procedimientos y triggers, no en
la aplicación. Entre los dos, 20 tablas, y los diagramas están en el repo.

**[Un chatbot que corre en el navegador](https://github.com/isabh17/IA1_Proyecto_17.github.io)**
Una red neuronal entrenada con Keras que clasifica 784 intenciones distintas.
Lo interesante fue exportarla a TensorFlow.js: no hay servidor detrás, el
modelo se descarga y responde desde el navegador.
[Se puede probar aquí](https://isabh17.github.io/IA1_Proyecto_17.github.io/).
